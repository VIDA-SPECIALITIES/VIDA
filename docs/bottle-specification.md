# Bottle specification record — Artifact 002, "The Living Curve Refined"

**Status: concept record. Not a manufacturing specification.** It transcribes what the supplied design board shows, separates stated values from inferences and conflicts, and lists what must be confirmed before any tooling, supplier or regulatory use. No units have been converted and no conflicting values have been resolved by guesswork.

## B. Values inferred from the artwork (not stated, and not for publication)

These were measured in pixels on the main front view (bottle from y ≈ 145 to ≈ 690 px, so ≈ 545 px tall). They are **relative proportions of a concept render**, smoothed to ignore 1-px guide lines. Accuracy is about ± 2–3 px (≈ ± 2%).

| Inference | Value | Method |
|---|---|---|
| Width at base ÷ width of the "2.25 UNITS" dimension line | ≈ 1.0 (both ≈ 122 px) | The dimension line spans x 343–465 px, matching the base |
| Overall height ÷ base width, **as drawn** | **≈ 4.1–4.4 : 1** | 545 px ÷ 122–132 px |
| Waist (narrowest body) width ÷ base width | ≈ 0.75 | ≈ 94 px ÷ ≈ 124 px |
| Neck/cap width ÷ base width | ≈ 0.42–0.47 | ≈ 50–58 px |
| Narrowest body point, position | ≈ 68% of height from the top (≈ 32% from the base) | Minimum smoothed width between 430 and 660 px |
| Upper body (shoulder) bulge | ≈ 50% of height from the top, width ≈ base width | Maximum width between 300 and 430 px |

## C. Conflicting or ambiguous values (unresolved, deliberately)

| # | Conflict | Values | Why it matters |
|---|---|---|---|
| C1 | **Stated vs drawn proportions** | Stated 7.5 ÷ 2.25 = **3.33 : 1**. Drawn ≈ **4.1–4.4 : 1** | At the drawing's scale, 2.25 units of width implies ≈ 10 units of height; or 7.5 units of height implies ≈ 1.7 units of width. One of them (or the render) is wrong |
| C2 | **Cap diameter** | 0.48 Units (Key Dimensions) vs 1.28 Units (Top View) | Different by 2.7×. 1.28 is also the "Neck Length" value, so it may be a copy error |
| C3 | **Base vs body width** | Base Diameter 2.35 Units vs Max Width (Body) 2.25 Units | The base is stated wider than the "max" body width. That is possible for a flared base, but then "max width" is mislabelled |
| C4 | **"2.25 UNITS" placement** | The table calls it Max Width (Body); the drawing places it at the base | The same figure is attached to two different features |
| C5 | **Narrowest point** | "18% of Total Height" vs a drawn waist at ≈ 32% from the base / 68% from the top | The reference point (from the top or the base) isn't stated, and neither reading matches the drawing |
| C6 | **Illegible row** | "Nasr/Naar Dlemeter — 55% of Total Height" | The label can't be read, and a diameter expressed as a share of height is dimensionally odd |
| C7 | **The unit itself** | "Units", undefined. The only metric value is the emboss depth, 0.6mm | No absolute size, volume or scale can be derived |
| C8 | **Lettering** | The emboss and cap "VIDA"/"V" are a serif face, not the official VIDA wordmark | A decision is needed on whether production artwork uses the brand wordmark |

The board also shows garbled label text (C6, "Langth", "Diamoter"), which suggests it was generated or quickly assembled. That is another reason not to treat its numbers as engineering data.

## D. Information still requiring confirmation before manufacturing

1. **The unit and the absolute scale**: a real height in mm, and the **fill volume** (not stated anywhere).
2. Resolution of conflicts C1–C6 in a **dimensioned technical drawing** (front and side elevations, sections at the neck, shoulder, waist and base).
3. **Neck finish/closure standard** (thread type, e.g. a PCO or GPI finish), cap material, cap colour and liner. None is stated.
4. **Materials**: the glass type ("low-iron" claim), PET resin and grade, wall thickness, weights; whether both expressions share one mould geometry.
5. **Emboss**: confirm the 0.6 mm depth with the tooling supplier, its position and the artwork (C8).
6. **Frost process**: acid-etch, spray or sandblast; gradient extent; compatibility with labels.
7. **Labelling/decoration area** (none is shown; "No need to reveal finished labels yet").
8. **Mechanical**: stability on filling lines (confirm the base flare), top-load, drop and pressure requirements (still vs functional).
9. **Regulatory and food contact**: material compliance, recyclability claims ("Highly Recyclable" is a claim), and labelling requirements with the relevant Nigerian regulator.
10. **Naming**: "Signature Collection" / "Everyday Collection" are board labels, not approved names.
